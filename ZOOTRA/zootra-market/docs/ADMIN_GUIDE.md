## Admin Login
To access the admin dashboard, navigate to the admin login page. Enter your admin credentials to log in. If you do not have an account, please contact the system administrator.

## Dashboard Overview
Upon logging in, you will be directed to the admin dashboard. Here, you can view key metrics such as:
- Total users (farmers, providers, buyers)
- Total listings
- Total bookings this month
- Revenue graph (future feature)
- Pending verifications count
- Recent signups

## Managing Listings
In the Manage Listings section, you can:
- View all product listings.
- Filter listings by category and status (pending/approved/rejected).
- Approve or reject listings with a reason.
- Delete listings that are no longer needed.
- Feature listings on the homepage for better visibility.

## Managing Services
In the Manage Services section, you can:
- View all service providers.
- Approve or reject provider applications.
- Edit service details as necessary.
- Remove services that are no longer offered.
- View service ratings and feedback.

## Managing Users
In the Manage Users section, you can:
- View all users (farmers, providers, buyers).
- Suspend or activate user accounts.
- Change user roles as needed.
- Delete user accounts that are inactive or violate terms.

## Verifying Sellers and Service Providers
In the Verify Sellers and Service Providers section, you can:
- Review pending seller verifications.
- View uploaded documents for verification.
- Approve sellers to grant them a verified badge on their listings.
- Reject applications with a reason provided.

## Managing Categories
In the Manage Categories section, you can:
- Add new product categories.
- Edit existing category names.
- Delete categories that are no longer relevant.
- Add subcategories to organize products better.
- Reorder categories for better user experience.

## Site Settings
In the Site Settings section, you can:
- Update contact information (phone, email).
- Update social media links.
- Change the location settings (e.g., from Kigali to other cities in the future).
- Update the "About Us" text and manage footer content.

## Viewing Reports
In the View Reports section, you can:
- Generate weekly and monthly reports.
- View top-selling products and most booked services.
- Identify the most active users.
- Export reports as CSV or PDF for further analysis.

## Platform Analytics
In the Platform Analytics section, you can:
- View user growth charts.
- Analyze listing growth trends.
- Monitor booking trends over time.
- View popular categories in a pie chart format.
- Access WhatsApp connection statistics for user engagement.

## Conclusion
This guide serves as a comprehensive resource for administrators to manage the Zootra Market platform effectively. For any further assistance, please refer to the support documentation or contact the technical team.
